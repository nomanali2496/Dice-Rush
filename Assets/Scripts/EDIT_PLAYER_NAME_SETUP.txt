================================================================================
                          🎨 SETUP IN UNITY
================================================================================

STEP 1: Create InputField for Player Name
──────────────────────────────────────────
1. Right-click GamePanel → UI → Input Field - TextMeshPro
2. Rename to: "PlayerNameInputField"
3. Position it where you want the name to show

STEP 2: Create Edit Button
───────────────────────────
1. Right-click GamePanel → UI → Button - TextMeshPro
2. Rename to: "EditNameButton"
3. Add text to button: "Edit"
4. Position it next to the InputField

STEP 3: Assign References in Inspector
────────────────────────────────────────
1. Select GameObject with PlayerProfileUI script
2. In Inspector, find PlayerProfileUI component:

   [UI References]
   ✓ Player Name Input Field → Drag PlayerNameInputField here
   
   [Buttons]
   ✓ Edit Name Button → Drag EditNameButton here
   
   [Edit Mode Settings]
   ✓ Edit Button Text → "Edit" (default)
   ✓ Save Button Text → "Save" (default)

STEP 4: Configure InputField
─────────────────────────────
1. Select PlayerNameInputField
2. In Inspector:
   ✓ Content Type → Standard (or Name)
   ✓ Character Limit → 20 (or your preference)
   ✓ Interactable → Will be controlled by script
   ✓ Read Only → Will be controlled by script

================================================================================
                          🎯 HOW IT WORKS
================================================================================

INITIAL STATE (Read-Only):
┌─────────────────────────────┐
│ Player Name: [usama      ]  │ ← InputField (read-only, grayed out)
│              [  Edit  ]     │ ← Button shows "Edit"
└─────────────────────────────┘

USER CLICKS "EDIT":
┌─────────────────────────────┐
│ Player Name: [usama      ]  │ ← InputField (editable, highlighted)
│              [  Save  ]     │ ← Button shows "Save"
└─────────────────────────────┘
- InputField becomes editable
- User can type new name
- Button text changes to "Save"

USER CLICKS "SAVE":
┌─────────────────────────────┐
│ Player Name: [new name   ]  │ ← InputField (read-only again)
│              [  Edit  ]     │ ← Button shows "Edit"
└─────────────────────────────┘
- Name is validated (min 3 chars)
- Saved to PlayFab cloud
- InputField becomes read-only
- Button text changes back to "Edit"
