================================================================================
                            QUICK START GUIDE
================================================================================

STEP 1: Install PlayFab SDK
  - Unity Package Manager → Add from git URL
  - URL: https://github.com/PlayFab/UnitySDK.git

STEP 2: Get PlayFab Title ID
  - Visit https://playfab.com
  - Create account and new Title
  - Copy your Title ID

STEP 3: Configure Unity
  - Window → PlayFab → Editor Extensions
  - Paste Title ID → Set Title ID

STEP 4: Create Scenes
  Required Scenes:
  □ SplashScreen (with UI Slider)
  □ LoginScene (with LoginUI.cs)
  □ RegistrationScene (with RegistrationUI.cs)
  □ GameScene (your main game)

STEP 5: Add to Build Settings
  - File → Build Settings
  - Add all scenes in order

STEP 6: Test!
  - Run SplashScreen scene
  - Register new account
  - Login and play

================================================================================
                        MOST COMMON COMMANDS
================================================================================

// Register
PlayFabManager.Instance.RegisterPlayer(email, password, name);

// Login
PlayFabManager.Instance.LoginWithEmail(email, password);

// Guest Login
PlayFabManager.Instance.LoginWithCustomId(SystemInfo.deviceUniqueIdentifier);

// Add Currency
PlayFabManager.Instance.AddCash(100);
PlayFabManager.Instance.AddCoins(50);

// Spend Currency
bool success = PlayFabManager.Instance.SpendCash(100);

// Get Player Data
PlayerData data = PlayFabManager.Instance.currentPlayerData;

// Save Data
PlayFabManager.Instance.SavePlayerData();

// Check Login Status
bool loggedIn = PlayFabManager.Instance.IsLoggedIn();

================================================================================
                            TROUBLESHOOTING
================================================================================

Problem: "PlayFabManager not found"
Solution: It's auto-created by SplashScreen

Problem: Login fails
Solution: Check Title ID in Unity PlayFab settings

Problem: Data not saving
Solution: Check internet connection

Problem: Password too short
Solution: Minimum 6 characters required

Problem: Invalid email
Solution: Must be valid email format (user@domain.com)
